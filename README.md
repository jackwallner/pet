# Biscuit

An iPhone log for two people caring for one dog. Cats are supported.

Open `Pet.xcodeproj` after `xcodegen generate`. The `Pet` scheme includes
unit tests, UI tests and the local StoreKit catalog.

The product contract is [the agreed plan](project-docs/product/plan.md).
Build and acceptance evidence is indexed in [verification](project-docs/verification/README.md).

The app runs locally with an unavailable iCloud container. Sharing and
production purchases require console provisioning before real-phone Gate 1.
