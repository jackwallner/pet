# V1 verification record

Date: 2026-11-06. Build 1.0.0, Debug, on a leased headless simulator and on GitHub's Macs.

## Commands

```bash
python3 scripts/verify.py
xcodebuild test -project Pet.xcodeproj -scheme Pet -destination "id=<leased UDID>" -parallel-testing-enabled NO
gh-sim all
```

## Results

- `verify.py` PASS: identity, production key format, products, both trials, metadata lengths, plist and source copy.
- Full suite: 46 of 46 passed (39 unit, 7 UI journeys), covering first-log onboarding, corrections, dose, invite paywall, sitter sheet, export, a simulated second caregiver, a stale medication notification that opens Now without logging, every main screen light and dark, large text, and the suggestion form with the network stubbed.
- GitHub's Macs: 44 passed, with the purchase test skipped (StoreKit stalls there) and the notification test unable to show its banner, now a skip too. Both passed on a local simulator.
- Real bug found and fixed in testing: tapping any notification aborted the app (async delegate thunk off the main thread).

## Not proved yet (Gate 1)

- CloudKit Production schema and transport. Household sharing cannot work for real users until the schema is deployed to Production.
- Two phones on two iCloud accounts: invitation acceptance, revocation, reinstall, import latency, long soak.
- Foregrounding producing an import inside the 5-minute staleness window, or Now reads "Stale" too often.
- Sandbox purchase through RevenueCat and customer attributes. Needs the RevenueCat Apple keys entered.
- A real suggestion through the live loop. Debug builds never send one.
